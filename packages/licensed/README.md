# @cullit/licensed

Private registry package for paid Cullit tiers (Pro, Team, Enterprise).

This package preloads paid collectors/generators/publishers and then runs the CLI.

| GitHub Release & GitLab Release publishers | ✓ | ✓ | ✓ |
