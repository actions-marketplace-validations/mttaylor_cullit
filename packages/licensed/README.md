# @cullit/licensed

Private registry package for Cullit paid tiers (Pro and Enterprise).

This package preloads pro collectors/generators/publishers and then runs the CLI.

## What's Included

| Feature | Free | Pro | Enterprise |
|---------|------|------|------------|
| AI providers (Anthropic, OpenAI, Gemini, Ollama) | ✗ | ✓ | ✓ |
| Jira & Linear enrichment | ✗ | ✓ | ✓ |
| Slack, Discord, Teams, Confluence, Notion publishers | ✗ | ✓ | ✓ |
| GitHub Release & GitLab Release publishers | ✗ | ✓ | ✓ |
| Hosted changelog & embeddable widget | ✗ | ✓ | ✓ |
| GitLab & Bitbucket collectors | ✗ | ✓ | ✓ |
| Dashboard & generation history | ✗ | ✓ | ✓ |
| GitHub App (auto-generate on release) | ✗ | ✓ | ✓ |
| Drafts & approvals | ✗ | ✓ | ✓ |
| Organization management & team API keys | ✗ | ✓ | ✓ |
| Branded widget | ✗ | ✓ | ✓ |
| Project templates | ✗ | ✓ | ✓ |
| Audit logs | ✗ | ✓ | ✓ |
| SSO / SAML | ✗ | ✗ | ✓ |

## Generation Limits

| Plan | Gens/month | Projects |
|------|-----------|----------|
| Free | 3 | 3 |
| Pro | 500+ (scales with seats) | 100+ |
| Enterprise | Unlimited | Unlimited |

## Install

```bash
npm install -g @cullit/licensed
```

## Registry

This package is published to a private registry and requires registry credentials.
