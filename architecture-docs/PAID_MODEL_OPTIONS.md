# Paid Model Options (Archived)

This document is intentionally archived for historical reference only.

## Status

- Cullit is now free and open source.
- Paid plan enforcement, checkout, and billing flows were retired.
- Sustainability moved to voluntary GitHub Sponsors donations.

## What changed

- Runtime gate checks in core were converted to permissive/open-access behavior.
- Billing API routes were moved to compatibility responses.
- Dashboard and pricing/support UX were updated to remove upgrade-driven flows.
- Documentation and legal pages were updated to match the sponsorship model.
